# Unveil AI- Tackle and understand entire codebases with ease.
Built as part of the Google DevFest Hackathon @ WashU

## Features:
- Upload entire codebases locally or via Github
- Get a structured walkthrough of your codebase, and get detailed answers to any question you might have, conceptual or literal
- "Call" your codebase, getting real access to a senior developer AI agent that understands your codebase and you can "rubber-duck" with to solve any problem
